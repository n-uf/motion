What this is

One lab for both packages

Every page here runs the real packages from this repository's sources, so a change in a package shows at once. Each page is a live demo you can drag around, and a set of scripted cases that drive it with real pointer and key events, frame by frame, and check the rules from what the page drew. There are two subjects: how things move (@n-uf/motion) and where things go in a window (@n-uf/placement/scene).

Motion

How things move

Two pages. Settle and tiling: every move is one critically damped settle that never passes its target, size changes reveal instead of stretching, and tiled windows reorder by drag. Drag intent and previews: a drop target shows only while you aim, and with the snap preview the held item settles into its slot.

Settle and tiling · Drag intent and previews

Document window

Where things go

One window as one Scene: a title bar, top and bottom bars, side columns, pages that scroll under them and floats above. Panels and toolbars take the largest form that fits and give way least recently used first; you drag them to any gap, float them, freeze them and reload them. Each case sets the window up, says what should happen and checks it, and every conformance row of @n-uf/placement/scene/cases plays on the same window.

Checks

Green or red, without a terminal

Checks runs every page's cases, or one group's, and lists each one as passing or failing with its first failure. Each page also has its own checks beside its demo.

Headless, every page answers window.__motionLab.runAll(filter?), and the Document window also window.__docwin.checkAll() (its cases and every conformance row).
