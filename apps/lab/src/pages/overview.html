What this is

One lab for both packages

Every page here runs the real packages from this repository's sources, so a change in a package shows at once. Each page is a live demo you can drag around, and a set of scripted scenarios that drive it with real pointer and key events, frame by frame, and check the rules from what the page drew.

@n-uf/motion

How things move

A critically damped settle for every move (never past its target), reveal for size changes, a drag intent that shows a drop target only while you aim, and a held drag that moves the real item.

Settle and tempo · Drag intent · Held drag and previews

@n-uf/placement

Where things go

Pure layouts: desk docks, rails and palettes that give way when room runs out, toolbar groups in hosts and zones, and the drop targets for each. State in, rects out.

Desk constructions · Tiling · Toolbar groups

Checks

Green or red, without a terminal

Checks runs every page's scenarios, or one group's, and lists each scenario as passing or failing with its first failure. Each page also has its own checks under its demo.

Headless, every page answers window.__motionLab.runAll(filter?); for example:

node desk-run-all.mjs "<the lab's address>#/placement/desk"
