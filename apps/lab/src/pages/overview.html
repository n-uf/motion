What this is

One lab for both packages

Every page here runs the real packages from this repository's sources, so a change in a package shows at once. Each page is a live demo you can drag around, and a set of scripted scenarios that drive it with real pointer and key events, frame by frame, and check the rules from what the page drew. There are two subjects: how things move (@n-uf/motion) and where things go along an edge (@n-uf/placement/stack).

Motion

How things move

Two pages. Settle and tiling: every move is one critically damped settle that never passes its target, size changes reveal instead of stretching, and tiled windows reorder by drag. Drag intent and previews: a drop target shows only while you aim, and the held drag moves the real item into its slot.

Settle and tiling · Drag intent and previews

Edge stack

Where things go

One stage: a side column, a top bar, pages that scroll under them and floats above. Panels and control groups take the largest form that fits and give way oldest first; you drag them into any gap, float them, freeze them and reload them. Each case is a preset on that stage, with its expectation and its check.

Panels in a column · Groups and toolbars · Dragging · Floats, saving, freeze

Checks

Every scenario, green or red

Runs every page's scenarios, or one section's, and lists each one with its first failure: the Motion pages, the Edge stack's cases and everything in the Archive.

Archive

On hold, still checked

Earlier models kept visible but no longer grown: the desk constructions, toolbar groups in hosts and zones, panels in columns, and the kit cases. Their scenarios still run on the Checks page; each page leaves once the Edge stack covers its cases.

Checks

Green or red, without a terminal

Checks runs every page's scenarios, or one group's, and lists each scenario as passing or failing with its first failure. Each page also has its own checks under its demo.

Headless, every page answers window.__motionLab.runAll(filter?); for example:

node desk-run-all.mjs "<the lab's address>#/placement/desk"
